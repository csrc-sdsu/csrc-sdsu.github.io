Vortex Shedding with MOLE MATLAB/Octave API

2D Non-hydrostatic incompressible Navier-Stokes equation in a channel. The image gallery illustrates a 2D fluid simulation of vortex shedding. The simulation was performed using the MOLE MATLAB/Octave API. The simulation combines Dirichlet inlet and Neumann outlet boundary conditions. The pressure has Neumann boundary condition on the top and bottom.
